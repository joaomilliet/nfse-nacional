# NFS-e Nacional

Issues, looks up, downloads (DANFSe PDF) and cancels the Brazilian national service invoice (NFS-e) through the federal Emissor Nacional API, signed with the company's ICP-Brasil A1 certificate. Every issue is a preview first and is sent only when confirmed. It needs the internet (HTTPS to the four nfse.gov.br hosts of the production and test environments) and reads the certificate file the user names.

An add-on for AiAudioHub: get it in AiAudioHub, Explore. Namespace `jpmm-nfse-nacional`, version 0.1.0.
